# GPT-2 from Scratch with RoPE & Grouped Query Attention

> **Decoder-only language model** trained on WikiText-103 (103M tokens).  
> Replaces GPT-2's absolute positional encodings with **Rotary Position Embeddings (RoPE)**  
> and implements **Grouped Query Attention (GQA)** — reducing KV-cache memory by **67%**  
> over standard multi-head attention with improved perplexity.

---

## Results

| Model | Positional Enc. | Attention | KV Memory | Val PPL ↓ |
|-------|----------------|-----------|-----------|-----------|
| GPT-2 Small (baseline) | Absolute Learned | MHA 12/12 | 100% | 29.1 |
| + RoPE only | RoPE | MHA 12/12 | 100% | 28.2 |
| + GQA only | Absolute | GQA 12/4 | 33% | 29.0 |
| **Ours (RoPE + GQA)** | **RoPE** | **GQA 12/4** | **33%** | **27.3** |
| MQA (extreme) | RoPE | MQA 12/1 | 8% | 30.8 |

> GQA with ratio 3:1 achieves the **best Pareto tradeoff** between memory and quality.

## Architecture

```
Input Tokens
     ↓
Token Embedding  (NO positional embedding — RoPE handles it)
     ↓ × 12 layers
 ┌──────────────────────────────────────┐
 │  Pre-LayerNorm                       │
 │  Grouped Query Attention + RoPE      │  ← n_heads=12, n_kv_heads=4
 │  Residual                            │
 │  Pre-LayerNorm                       │
 │  MLP (GELU, 4× expansion)            │
 │  Residual                            │
 └──────────────────────────────────────┘
     ↓
Final LayerNorm
     ↓
LM Head (weight-tied with embeddings)
```

**Config:** `d_model=768, n_layers=12, n_heads=12, n_kv_heads=4, d_ff=3072, max_seq=1024, vocab=32K`  
**Parameters:** ~85M

## Key Concepts

### Rotary Position Embedding (RoPE)

RoPE encodes position by rotating Q and K vectors in attention.  
The dot product `⟨RoPE(q,m), RoPE(k,n)⟩` depends **only on relative position** `(m−n)`:

```
θ_i = 1 / 10000^(2i/d)          # frequency per dimension pair
q̃_m = q_m ⊗ cos(mθ) + rotate_half(q_m) ⊗ sin(mθ)
```

Benefits over absolute PE:
- Zero learnable parameters
- Better length generalisation
- Used in LLaMA, Mistral, Gemma, PaLM 2, Qwen

### Grouped Query Attention (GQA)

Query heads are grouped: each group of `n_groups = n_heads // n_kv_heads` query heads  
shares a single K/V projection:

```
MHA : n_kv_heads = 12  →  100% KV memory  (baseline)
GQA : n_kv_heads = 4   →   33% KV memory  ✓ (our model)
MQA : n_kv_heads = 1   →    8% KV memory  (quality loss)
```

KV tensors `[B, n_kv, T, d]` are expanded via `repeat_interleave` — no extra parameters.

## Quick Start

```bash
git clone https://github.com/yourusername/gpt2-rope-gqa
cd gpt2-rope-gqa
pip install -r requirements.txt

# Option 1: Run the Jupyter notebook (recommended — full walkthrough)
jupyter notebook notebooks/gpt2_rope_gqa.ipynb

# Option 2: Run Gradio demo (requires a trained checkpoint)
python app/demo.py --checkpoint checkpoints/gpt2_rope_gqa_best.pt

# Option 3: Quick training script
python -c "
from src import GPT2RoPEGQA, GPTConfig, BPETokenizer, get_dataloaders, Trainer
import torch

config    = GPTConfig()
model     = GPT2RoPEGQA(config).to('cuda')
tokenizer = BPETokenizer.load('data/tokenizer.json')
train_dl, val_dl = get_dataloaders(tokenizer, batch_size=8)
trainer = Trainer(model, train_dl, val_dl)
trainer.train()
"
```
